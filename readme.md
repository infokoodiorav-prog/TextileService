# Textile Service – Multi-Page Business Platform

A modern multi-page B2B service website concept for a fictional textile service company.
Built to simulate a real enterprise-level platform with multilingual support, interactive UX flows, and guided service selection.

---

## 🚀 Overview

Textile Service is a conceptual business platform designed to demonstrate how a real-world service company website could function.

The focus is on:
- Structured service presentation
- Multilingual user experience
- Interactive guidance system for users
- Conversion-oriented UI/UX design

---

## 🎯 Key Features

- 🌍 Multi-language support (Estonian, English)
- 🧭 Multi-page structure
  - Solutions
  - About
  - News
  - Contact
- 🎠 Homepage carousel with CTA-driven slides
- 🤖 Interactive chatbot assistant
  - Guides users to services
  - Helps selection flow
- 🪟 Popup & modal system
  - Quote request form
- 🧠 Smart service selection flow
- 📱 Fully responsive design

---

## 🧱 Tech Stack

- HTML5, CSS3, JavaScript (Vanilla)
- JSON-based translation system
- Font Awesome & Flag Icons

## 🏋️ Project Concept

This project was built to demonstrate:

- How a multilingual B2B website can be structured
- How guided UX flows improve user conversion
- How interactive UI components can be built without frameworks
- How modular frontend architecture scales across multiple pages

---

## 🌍 Language Support

The site includes a simple translation system using `data-i18n` attributes.

Supported languages:
- Estonian (default)
- English
